New `rich-text-editor` module: controlled tiptap-based markdown editor with a configurable toolbar (groups + `toolbarExtra` app slot), label/icon props with English defaults, caret-preserving external sync, and a markdown round-trip contract. Adds `@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/pm` and `tiptap-markdown` as dependencies.
